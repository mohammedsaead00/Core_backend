## Goal

Give you a copy-paste terminal runbook to: run the API, see and try every endpoint in a browser, and inspect the SQL Server database. Three small deliverables, then the runbook steps themselves.

## Deliverable 1 — Swagger UI so you can see & try endpoints in the browser

Right now only raw JSON exists at `/openapi/v1.json` (Development only). I'll add the standard Swagger UI:

- `dotnet add src/CoreGym.Api package Swashbuckle.AspNetCore`
- In `Program.cs` (Development block): `app.UseSwagger(); app.UseSwaggerUI();` → browsable, try-it-out UI at **`/swagger`**
- No other changes; existing `AddOpenApi` stays for the JSON contract

## Deliverable 2 — `scripts/dev-token.ps1` (tiny helper)

A 10-line script that prints a valid HS256 dev JWT for a user id (same signing key as your dev API) so you can try authenticated endpoints from the terminal without the test suite:

```powershell
powershell -File scripts/dev-token.ps1 -UserId "<guid>"   # prints the token
```

## Deliverable 3 — `docs/RUNNING_LOCALLY.md` — the runbook you asked for

Copy-paste steps (PowerShell), including:

1. **Prerequisites check** — `dotnet --version`, `sqllocaldb info MSSQLLocalDB`, `dotnet ef --version`
2. **Fastest way to see everything working** — `powershell -ExecutionPolicy Bypass -File verify.ps1` (builds, runs 140 tests, boots the API, walks flows, cleans up)
3. **Run the API for real** — create dev DB via `sqlcmd`, start with env vars (connection string, JWT signing key, `Database__MigrateOnStartup=true`), watch migrations apply on boot, API on `http://localhost:5080`
4. **See all endpoints** — open `http://localhost:5080/swagger` (try-it-out UI) and `/openapi/v1.json`; full documented list in `docs/API.md`
5. **Try endpoints from the terminal** — mint a token with the helper, then `curl` examples for the full happy path: `POST /api/me` → `PUT /api/me/onboarding` → `POST /api/nutrition/logs` → `GET /api/me/summary/{today}` → `POST /api/me/streak/activity` → `POST /api/workouts/sessions` → chat, coach content, etc.
6. **See your database** — `sqlcmd` one-liners: list all 42 tables, row counts, sample queries (`SELECT * FROM profiles`, `daily_summary`, `user_streaks`); plus the connection string to paste into SSMS / Azure Data Studio (`(localdb)\MSSQLLocalDB`, DB `CoreGym_Dev`)
7. **Stop & clean up** — Ctrl+C the API, optional `DROP DATABASE`
